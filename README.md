# CuePoint · Descargas

Instaladores oficiales de **CuePoint**, software de presentación en vivo para congregaciones:
letras, versículos, video y cronómetro, en español y sin necesidad de internet.

**Descarga la versión más reciente en [Releases](../../releases/latest)** o desde
[cue-point-sigma.vercel.app/descargar](https://cue-point-sigma.vercel.app/descargar/).

| Archivo | Para |
|---|---|
| `CuePoint_<versión>_aarch64.dmg` | Mac con Apple Silicon (M1 o posterior) |
| `CuePoint_<versión>_x64.dmg` | Mac con Intel |
| `CuePoint_<versión>_x64-setup.exe` | Windows 10 u 11 |

## Prueba y licencia

CuePoint funciona completo **14 días**. Después sigue funcionando con una marca
"Versión de prueba" en la pantalla hasta que actives tu licencia en
**Ajustes → Licencia**. La licencia se verifica sin internet.

## Primera instalación

Los instaladores todavía no están firmados por Apple ni Microsoft:

- **Mac:** arrastra CuePoint a Aplicaciones. La primera vez, clic derecho sobre CuePoint →
  Abrir → Abrir.
- **Windows:** si aparece "Windows protegió tu PC", elige Más información → Ejecutar de
  todas formas.

---

Este repositorio sólo contiene los instaladores. El código fuente de CuePoint es privado.
Las letras de canciones requieren la licencia CCLI de cada iglesia; CuePoint no incluye ni
distribuye letras.
